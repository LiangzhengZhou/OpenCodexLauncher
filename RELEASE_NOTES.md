# OpenCodex Launcher 3.0.3

## 中文

正式更换为粉色图标。裁掉原图多余的透明留白，保留安全边距，增大窗口、任务栏和 EXE 中图标主体的显示比例；提供 16、24、32、48、64、128、256 像素图标并保持原始比例。

本次为图标更新，保留供应商、API Key、模型、Desktop 关联及关键版本回退功能。可通过软件内“检查启动器更新”升级。关键回退列表仍仅包含已确认的 2.6.5。

## English

Replace the application icon with the approved pink artwork. Trim excess transparent margins with safe padding for a larger visible symbol in the window, taskbar and executable. Include 16–256 px icon frames with the artwork aspect ratio preserved.

This icon-only update preserves configuration and existing features, including confirmed milestone rollback to 2.6.5. Upgrade through the built-in launcher update check.
