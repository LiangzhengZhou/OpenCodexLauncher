# OpenCodex Launcher 3.0.4

## 中文

- 打开后常驻 Windows 系统托盘，使用现有粉色图标。关闭窗口或最小化时隐藏到托盘，保留编辑内容和后台操作。
- 左键点击图标恢复窗口；右键提供“显示主窗口”和“退出启动器”，菜单支持中英文。要完全退出，请使用“退出启动器”。
- 更新和关键版本回退会真正退出启动器，避免隐藏到托盘后阻塞文件替换；退出清理托盘图标并取消启动器操作。
- 图标可能位于任务栏 ^ 的隐藏图标区，由 Windows 管理显示位置；不新增开机自启动。

保留供应商、API Key、模型、Desktop 关联及运行时路径。可通过软件内“检查启动器更新”升级。关键回退列表仍仅包含已确认的 2.6.5。

## English

- Add a Windows notification area icon. Closing or minimizing hides the window while keeping drafts and background work.
- Click the icon to restore the window. Right-click for localized Show main window / Exit launcher commands. Use Exit launcher to fully quit.
- Updates and milestone rollback still fully exit before replacing files. Final exit releases the tray icon and cancels launcher operations.
- Windows may place the icon in the ^ overflow panel. This does not enable startup with Windows.

Existing providers, keys, model selections, Desktop association and runtime paths are preserved. Upgrade through the built-in launcher update check. Version 2.6.5 remains the only confirmed rollback milestone.

Windows x64 · .NET Framework 4.8 · MIT
